## 主要变更

- **输入框「OpenViking」胶囊可开关显示**：胶囊默认不再出现在输入框旁，配置页新增「输入框胶囊」卡片，「隐藏 / 显示」二选一，保存立即生效。隐藏只改界面：每个会话的记忆仍默认开启，要关掉某个会话的读写仍得用胶囊。开关保存在本插件自己的 `$DSH_HOME/plugin-data/dsh-openviking-manager/preferences.json`，不写进 `ovcli.conf`。
- **插件页详情改用精简文档**：DSH 插件页的长文不再显示整份 README，改为 `docs/details/` 下的中英文 DETAIL 文档——简介、功能列表、仓库地址。语言跟随页面语言，其他语言回落到英文文档。
- **内部**：英文 README 更名 `README_EN.md` → `README.en.md`（`files` 与文档间链接同步）；「输入框胶囊」卡片移到「项目记忆隔离」上方，e2e 补一条顺序断言；e2e 夹具一律使用临时 preferences 文件，不会读到本机的真实设置。

## 安装

```bash
# 正式版（npm）

# 同一版本的 GitHub Release 附件
dsh plugin --profile web add https://github.com/xbzbing/dsh-openviking-manager/releases/download/v0.5.1/dsh-openviking-manager-0.5.1.tgz
```

## English

- **The input-box "OpenViking" pill can be switched off**: the pill no longer shows next to the input box by default. A new "Composer pill" card on the configuration page offers "Hide / Show", and the saved value applies immediately. Hiding changes only the interface: memory still stays on for every session, and turning one session off still needs the pill itself. The setting lives in this plugin's own `$DSH_HOME/plugin-data/dsh-openviking-manager/preferences.json` and is never written to `ovcli.conf`.
- **A short detail page instead of the whole README**: the DSH plugin page no longer shows the full README. It reads the Chinese and English DETAIL documents in `docs/details/` — a short introduction, the feature list and the repository link. The language follows the page, and other languages fall back to the English document.
- **Internal**: the English README was renamed `README_EN.md` → `README.en.md` (with `files` and cross-links updated); the "Composer pill" card moved above "Project memory isolation", with an e2e order assertion; e2e fixtures now always use a temporary preferences file, so they can never read this machine's real settings.
