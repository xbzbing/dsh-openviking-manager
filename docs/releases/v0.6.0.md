## 主要变更

- **连接测试显示服务端版本**：验证连接成功后，结果旁直接显示 OpenViking 的版本徽标（如 `OpenViking 0.5.x`），窄屏自动换行；托管服务对匿名 `/health` 返回 401 时，用已保存的用户 Key 重试成功后再读取版本。地址是否填对、服务是不是目标版本，可以当场确认。
- **新增「MCP remember」开关**：配置页可禁止 agent 显式调用 `mcp__openviking__remember`，并在每个会话的工具列表中直接摘除该工具，而不是等调用后才报错。该工具没有 peer 参数，显式调用会写入用户级空间；自动捕获和其他 OpenViking MCP 工具不受影响，仍按当前项目 peer 写入。
- **默认禁止显式 remember**：没有保存过该偏好的安装，升级后默认禁止；已显式保存「允许」的安装保持允许。开关保存后立即对当前会话生效，不需要重启 DSH 或重新加载官方插件。
- **内部**：中英文文案按语言拆分到 `src/client/locales/zh.ts` 与 `en.ts`，`zh.ts` 作为 key 唯一真源，`en.ts` 必须覆盖同一组 key；新增或修改文案时两份字典同步维护。

## English

- **The connection probe shows the server version**: after a successful verify, the result now sits next to an OpenViking version badge (for example `OpenViking 0.5.x`), wrapping on narrow screens; when a hosted service answers 401 to the anonymous `/health`, the probe retries with the stored user key and reads the version from that successful response. You can confirm both the address and the server version at a glance.
- **New "MCP remember" switch**: the configuration page can block the agent's explicit `mcp__openviking__remember` calls and remove the tool from every session's tool list instead of rejecting it only after a call. The tool takes no peer argument, so an explicit call writes to the user-level space; automatic capture and the other OpenViking MCP tools are unaffected and still write to the current project's peer.
- **Explicit remember is blocked by default**: installations that never saved this preference now default to blocked after upgrading; installations that explicitly saved "allow" stay allowed. A saved switch applies to the current sessions immediately — no DSH restart or official-plugin reload needed.
- **Internal**: the zh/en copy now lives in per-language files, `src/client/locales/zh.ts` and `en.ts`; `zh.ts` is the only key source of truth and `en.ts` must cover the same keys, so both dictionaries must be updated together.
